# 🏆 GOLDEN TOURNAMENT (스위스-Elo 골든 토너먼트)

> **"조기 탈락 없는 공정한 스위스 균등 노출과 실시간 Elo 래더, 골든 파이널 4강 챔피언십이 결합된 유튜브 영상/음악 토너먼트"**

기존 이상형 월드컵의 치명적인 단점이었던 **"1라운드 패배 시 다시는 볼 수 없는 문제(대진운)"**를 해결하기 위해 설계된 차세대 웹 애플리케이션입니다.

---

## ✨ 핵심 기능

1. **1단계 스위스 균등 노출 (Fair Swiss Phase)**
   - 모든 참가 영상이 최소 2~3회 이상 의무적으로 대결에 등장하여 공평한 초기 전적과 레이팅을 형성합니다.
2. **2단계 실시간 Elo 라이벌 래더 (Elo Ladder Phase)**
   - 점수 격차가 적은 라이벌 영상끼리 팽팽한 1:1 대결을 펼치며 K-팩터 기반 실시간 순위 변동이 일어납니다.
   - ⚡ 퀵 코스(16매치), ⚖️ 표준 밸런스(28매치), 🎯 마스터 래더(45매치) 중 취향에 따라 선택 가능합니다.
3. **3단계 골든 파이널 4강 토너먼트 (Golden Final 4)**
   - 상위 1~4위 후보가 자동으로 진출하여 4강 1경기(1위 vs 4위) ➔ 4강 2경기(2위 vs 3위) ➔ 결승전(Grand Final)을 통해 최후의 우승자를 가립니다.
4. **4단계 명예의 전당 & 인터랙티브 티어표 (Tier Maker)**
   - 1위 우승 챔피언 연출 및 YouTube 감상 링크.
   - S, A, B, C, D 등급별 티어표 자동 생성 및 마노사바 스타일 드래그 앤 드롭 순위 미세 조정.
   - 결과 순위표 텍스트 복사 & 고화질 PNG 티어표 이미지 다운로드 기능.
5. **Zero-Lag 60FPS 극강 최적화**
   - iframe 객체를 매 라운드마다 재생성하지 않고 좌/우 2개의 플레이어 인스턴스를 영구 풀로 재활용하여 가비지 컬렉션(GC) 스파이크를 원천 차단했습니다.
   - 키보드 A / D (또는 좌/우 방향키) 단축키를 지원합니다.

---

## 🚀 실행 방법

### 방법 1: 로컬 웹 서버 (권장)
* 폴더 내의 **`start.bat`** 파일을 더블 클릭하면 자동으로 로컬 서버(`http://localhost:8000`)가 실행되고 브라우저가 열립니다.

### 방법 2: Live Server
* VS Code의 Live Server 익스텐션 또는 로컬 웹 서버에서 `index.html`을 실행합니다.
